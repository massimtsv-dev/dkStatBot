# dkStatBot — бот сбора статистики DK FILMS

Telegram-бот: онбординг сотрудника, планирование недели с ИИ, регулярные вопросы по 30-дневному циклу,
периодические вопросы (месяц / квартал / полгода / год), ИИ-анализ ответов и уведомления преподавателям,
если сотруднику нужна помощь.

## Запуск

Секретов в коде нет — всё задаётся в файле конфигурации или переменными окружения (переменная важнее файла).
Список параметров — в `local.properties.example`.

**На сервере (VPS)** — конфиг лежит отдельно, при обновлении заменяется только jar:

```ini
# /etc/systemd/system/dkstatbot.service
[Service]
# рабочая папка — здесь будет лежать statbot.db
WorkingDirectory=/opt/dkstatbot
Environment=CONFIG_PATH=/etc/dkstatbot/bot.properties
ExecStart=/usr/bin/java -jar /opt/dkstatbot/statbot.jar
Restart=always
```

Вместо файла можно подключить переменные: `EnvironmentFile=/etc/dkstatbot/bot.env` (формат `KEY=value`).

**Локально** — положи `local.properties` в корень проекта и запусти `main()` в `src/main/kotlin/com/statbot/bot/Main.kt`.

Сборка: `gradlew build` → `build/libs/statbot.jar`.

Старая база `statbot.db` подхватывается автоматически: новые колонки и таблица `weekly_plans` добавляются при старте.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Онбординг (для нового) или главное меню |
| `/profile`, кнопка «👤 Мой профиль» | Просмотр и редактирование профиля |
| `/survey` | Пройти сегодняшний опрос вручную |
| `/iamteacher <ключ>` | Получить роль преподавателя (сообщение с ключом удаляется; без `TEACHER_PASSWORD` команда отключена) |
| `/teacher` | Панель преподавателя: статистика за день/7/30 дней, по ученикам, алерты ИИ |
| `/iamstudent` | Вернуть роль сотрудника |
| `/test` | Список тестовых сценариев |

### Тестовые сценарии (ничего не пишут в постоянную БД)

`/test_onboarding`, `/test_plan` (Сценарий 1), `/test_friday`, `/test_friday_noplan`, `/test_monday`,
`/test_monday_noplan`, `/test_day N`, `/test_monthly`, `/test_quarterly`, `/test_halfyear`, `/test_yearly`, `/test_stop`.
В тесте напоминание о неподтверждённом плане приходит через 1 минуту. Отключить тесты на проде: `TEST_COMMANDS=false`.

## Расписание (МСК)

- ПН–ЧТ 10:00 — вопросы дня (ПН — проверка плана недели, ВТ–ЧТ — вопросы 30-дневного цикла, если они есть в этот день).
- ПТ 18:00 — итоги недели и план на следующую.
- ПН–ПТ 20:00 — напоминание тем, кто не закончил опрос.
- Через 1 час после начала планирования — одно напоминание, если план не подтверждён.

30-дневный цикл для нового сотрудника стартует с первого понедельника следующего месяца после онбординга.
Периодические вопросы ставятся в дни с одним вопросом (СР, дни 3/10/17/24) — см. `survey/Schedule.kt`.

## Структура

```
bot/            Main.kt (точка входа), BotApp (приём апдейтов, команды), TeacherPanel
survey/         Steps (все вопросы), Schedule (что спрашивать в какой день), SurveyEngine, PlanningFlow, Session
ai/             OpenAiClient, Prompts (все промпты), PlanAssistant, ReportAnalyst
telegram/       лёгкий клиент Bot API на java.net.http + корутинах
db/             таблицы Exposed и Repository
notifications/  SchedulerService — рассылки по расписанию
```
